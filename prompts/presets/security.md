Trace untrusted input, identity, and data across trust boundaries. Find injection,
authentication and authorization failures, sensitive-data or secret exposure, unsafe parsing
or deserialization, privilege misuse, and availability abuse. Require a concrete path from a
missing or bypassed control to security impact; recognizing a risky pattern is insufficient.
Name the attacker and show an authority gain across a real trust boundary. If exploiting an
environment variable, configuration value, endpoint, local socket, filesystem path, or other
input already requires authority equivalent to the claimed impact, it is not a vulnerability.
